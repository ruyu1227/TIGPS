# 高素養，反而深陷網路沉迷：青少年數位素養與網路沉迷

本專案分析「臺灣數位世代青少年的成長歷程追蹤研究（TIGPS）」第二波學生問卷資料，探討青少年數位素養與網路成癮之間的關係。

## 研究動機

會使用數位工具，是否代表能駕馭數位生活？本研究發現，在 7,335 名有效樣本中，約三成青少年同時具備高數位素養與高網路成癮傾向，顯示「會操作」不等於「能自律」。研究進一步以效果量分析與邏輯斯迴歸，辨識出使這群青少年深陷網路沉迷的風險與保護因素。

## 資料來源

本研究使用「臺灣數位世代青少年的成長歷程追蹤研究（TIGPS）」第二波學生問卷資料，資料所有權屬原研究團隊，本專案僅公開分析程式碼，不包含原始資料。

## 分析流程

1. 資料清理與分組（依數位素養、網路成癮分數中位數劃分）
2. 效果量分析（Cohen's d / Cramér's V）篩選變數
3. 邏輯斯迴歸（含VIF共線性檢查）建立最終模型
4. 視覺化（散佈圖、棒棒糖圖、森林圖）

## 使用工具

R（dplyr, ggplot2, broom, patchwork）
